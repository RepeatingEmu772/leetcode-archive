transactions (
    transaction_id INT,
    customer_id INT,
    amount DECIMAL,
    transaction_date DATE
)

Return each customer’s total transaction amount and number of transactions during September 2026. 
Include only customers whose total exceeds $10,000, ordered by total amount descending.
Output columns: customer_id, total_amount, transaction_count.

SELECT
    customer_id,
    SUM(amount) AS total_amount,
    COUNT(*) AS transaction_count
FROM transactions
WHERE transaction_date >= '2026-09-01'
  AND transaction_date < '2026-10-01'
GROUP BY customer_id
HAVING SUM(amount) > 10000
ORDER BY total_amount DESC;

Return each customer’s average transaction amount and rank customers from highest average to lowest. 
Customers with equal averages should share a rank, with no gaps between ranks. Use all dates

SELECT
    customer_id,
    AVG(amount) AS avg_amount,
    DENSE_RANK() OVER (
        ORDER BY AVG(amount) DESC
    ) AS customer_rank
FROM transactions
GROUP BY customer_id
ORDER BY customer_rank;

For averages 500, 500, 300:
- RANK() → 1, 1, 3
- DENSE_RANK() → 1, 1, 2
- ROW_NUMBER() → assigns unique numbers 1, 2, 3

Find customers who made at least 3 transactions during September 2026. Return:
- customer_id
- Total transaction amount as total_amount
- Number of transactions as transaction_count
Order by total_amount from highest to lowest.

SELECT 
    customer_id,
    SUM(amount) AS total_amount,
    COUNT(*) AS transaction_count
FROM transactions
WHERE transaction_date > '2026-08-31'
AND transaction_date < '2026-10-1'
GROUP BY customer_id
HAVING transaction_count >= 3
ORDER BY total_amount DESC;

customers (
    customer_id INT,
    customer_name VARCHAR
)

Using customers and transactions, return every customer’s ID, name, and total transaction amount across all dates.
Include customers with no transactions and show their total as 0.

SELECT
    c.customer_id,
    c.customer_name,
    COALESCE(SUM(t.amount), 0)
FROM customers c
LEFT JOIN transactions t
    ON c.customer_id = t.customer_id
GROUP BY customer_id;

Modify this query to return only customers with no transactions. Return just their ID and name; you don’t need aggregation.

SELECT
    c.customer_id,
    c.customer_name,
FROM customers c
LEFT JOIN transactions t
    ON c.customer_id = t.customer_id
WHERE COUNT(t.*) > 0
GROUP BY customer_id;

Find each customer’s largest transaction amount, including only customers with at least three transactions.

SELECT 
    customer_id,
    MAX(amount) AS max_amount
from transactions
GROUP BY customer_id
HAVING COUNT(*) >= 3;

Find customers whose average transaction amount exceeds $500. Return customer_id, avg_amount, and transaction_count, ordered by average amount descending.

SELECT
    customer_id,
    AVG(amount) as avg_amount,
FROM transactions
GROUP BY customer_id
HAVING AVG(amount) > 500
ORDER BY avg_amount DESC;

Using transactions, return each customer’s:
- customer_id
- Total number of transactions as transaction_count
- Number with amount > 1000 as large_transaction_count
Keep customers with zero large transactions if they have other transactions.

SELECT
    customer_id,
    COUNT(*) as ts_count,
    SUM(CASE WHEN amount > 1000 THEN 1 ELSE 0 END) AS large_transaction_count
FROM transactions
GROUP BY customer_id;

Using customers(customer_id, customer_name) and transactions, return the ID and name of customers with no transactions. Use a LEFT JOIN.

SELECT
    c.customer_id,
    c.customer_name
FROM customers c
LEFT JOIN transactions t
    ON c.customer_id = t.customer_id
GROUP BY (t.customer_id)
HAVING COUNT(t.transaction_id) = 0;
